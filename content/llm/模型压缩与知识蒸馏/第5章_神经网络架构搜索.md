# 第 5 章 神经网络架构搜索

神经网络架构搜索（Neural Architecture Search, NAS）是一种自动化设计神经网络架构的技术，旨在替代人工手工设计网络的繁琐过程，通过算法在巨大的架构空间中搜索最优网络结构。

## 5.1 NAS基本框架

### 5.1.1 三要素：搜索空间、搜索策略、评估策略

任何NAS方法都由三个核心组件构成：

- **搜索空间（Search Space）**：定义可能的架构集合。包括操作类型（卷积、池化、跳跃连接等）、层数、通道数、连接方式等。搜索空间的设计决定了NAS的上限。
- **搜索策略（Search Strategy）**：在搜索空间中找到最优架构的方法，包括强化学习、进化算法、梯度优化、贝叶斯优化等。
- **评估策略（Evaluation Strategy）**：快速估算候选架构性能的方法，如完整训练、权重共享（one-shot NAS）、性能预测器等。

### 5.1.2 NAS的发展历程

NAS经历了三个主要发展阶段：

1. **早期的强化学习NAS**（Zoph等2017，搜索需800 GPU天）
2. **基于权重共享的one-shot NAS**（ENAS，2018，成本降低至1000x）
3. **可微分NAS**（DARTS，2019，采用梯度优化，仅需1.5 GPU天）

## 5.2 经典NAS方法详解

### 5.2.1 强化学习NAS（NASNet）

Zoph和Le（2017）使用RNN控制器生成网络架构描述，通过在验证集上训练并评估候选网络，以精度作为奖励信号训练控制器（REINFORCE算法）。

NASNet在搜索到的cell上重复堆叠构建完整网络，在ImageNet上超越了当时所有手工设计网络，但搜索成本极高（800 GPU-days）。

### 5.2.2 可微分架构搜索（DARTS）

DARTS（Differentiable ARchiTecture Search）通过混合操作（mixed operations）将离散的架构搜索转化为连续优化问题：

对每条边的候选操作赋予连续的架构权重 α，输出为所有操作的加权和：

```
y = Σ_o exp(α_o) / Σ_o' exp(α_o') × o(x)
```

训练时交替优化网络权重 w（用训练集梯度）和架构权重 α（用验证集梯度），搜索完成后保留每条边权重最大的操作，得到离散架构。搜索仅需1.5 GPU-days。

### 5.2.3 硬件感知NAS（MNASNet、Once-for-All）

硬件感知NAS将推理延迟直接加入优化目标：

```
Maximize ACC(m) × [LAT(m)/T]^(-w)
```

其中 T 为延迟目标，w 控制延迟惩罚强度。MNASNet通过在真实移动设备上测量延迟进行搜索，找到精度-延迟最优权衡点，催生了MobileNetV3系列。

## 5.3 搜索空间设计

### 5.3.1 Cell-based搜索空间

将完整网络分解为重复的Cell单元，搜索cell的内部结构，然后将其堆叠构建完整网络。每个cell是有向无环图（DAG），节点为特征图，边为操作。

候选操作集合通常包含：
- 3×3卷积
- 5×5卷积
- 3×3最大池化
- 3×3平均池化
- 恒等映射（skip connection）
- 零操作（无连接）

### 5.3.2 分层搜索空间

现代NAS（如EfficientNet）引入复合缩放（Compound Scaling），同时搜索网络宽度（width）、深度（depth）和输入分辨率（resolution），用单一复合系数φ控制：

```
depth: d = α^φ
width: w = β^φ
resolution: r = γ^φ
```

其中 `α·β²·γ² ≈ 2`，约束总计算量缩放约为 2^φ。EfficientNet-B7在ImageNet上以最少参数量达到最高精度。

## 5.4 操作Demo：DARTS实践

### 5.4.1 DARTS关键代码实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

# 候选操作集
OPS = {
    'skip_connect': lambda C: nn.Identity(),
    'conv_3x3':     lambda C: nn.Conv2d(C, C, 3, padding=1, bias=False),
    'conv_5x5':     lambda C: nn.Conv2d(C, C, 5, padding=2, bias=False),
    'max_pool_3x3': lambda C: nn.MaxPool2d(3, stride=1, padding=1),
    'avg_pool_3x3': lambda C: nn.AvgPool2d(3, stride=1, padding=1),
    'zero':         lambda C: Zero(),
}

class MixedOp(nn.Module):
    '''DARTS混合操作：对所有候选操作加权求和'''
    def __init__(self, C):
        super().__init__()
        self._ops = nn.ModuleList([OPS[k](C) for k in OPS])

    def forward(self, x, weights):
        # weights是softmax后的架构权重alpha
        return sum(w * op(x) for w, op in zip(weights, self._ops))

class DARTSCell(nn.Module):
    def __init__(self, steps, C):
        super().__init__()
        self.steps = steps
        self._ops = nn.ModuleList()
        # 每对节点之间一个混合操作
        for i in range(steps):
            for j in range(i+2):
                self._ops.append(MixedOp(C))

    def forward(self, s0, s1, weights):
        states = [s0, s1]
        offset = 0
        for i in range(self.steps):
            # 聚合所有前驱节点的输出
            s = sum(self._ops[offset+j](h, weights[offset+j])
                    for j, h in enumerate(states))
            offset += len(states)
            states.append(s)
        return torch.cat(states[-4:], dim=1)
```

## 5.6 NAS的挑战与未来

### 5.6.1 搜索代理与真实性能的差距

NAS通常在代理任务（小数据集/少训练轮次）上搜索架构，迁移到目标任务时可能出现性能差距（proxy gap）问题。One-shot NAS通过权重共享缓解了这一问题，但权重偏差（weight coupling）仍是挑战。

### 5.6.2 Zero-shot NAS

Zero-shot NAS无需任何训练即可评估架构质量，通过在随机初始化网络上计算指标（如梯度范数、Jacobian矩阵的秩）来预测最终性能，搜索时间可压缩至分钟级。
