# 第 6 章  知识蒸馏
知识蒸馏（Knowledge Distillation, KD）由Hinton等人于2015年提出，其核心思想是让小型的学生网络（Student Network）学习大型的教师网络（Teacher Network）的行为，从而在保持轻量化的同时提升学生网络的性能。
## 6.1 知识蒸馏基本原理
### 6.1.1 师生框架
知识蒸馏建立在一个直觉上：由大模型产生的软概率（soft probabilities）包含比硬标签（one-hot labels）更丰富的信息。例如，对于一张猫的图片，教师模型可能输出：猫0.88、豹0.07、狗0.03，这种类间关系信息（猫更像豹而非狗）无法从硬标签中获取。
### 6.1.2 软标签与温度参数
Hinton引入温度参数T对softmax输出进行软化：
q_i = exp(z_i/T) / Σ_j exp(z_j/T)
当T=1时为标准softmax；T>1时概率分布变得更平滑，类间相似性信息更加突出；T<1时分布变尖锐，接近argmax。蒸馏训练时通常T=3~5，推理时T=1。
### 6.1.3 经典蒸馏损失函数
原始KD论文中，学生的总损失函数为：
L_total = α × L_CE(y, p_S) + (1-α) × T² × L_KL(p_T, p_S)
其中：L_CE 为学生预测与真实标签的交叉熵；L_KL 为学生与教师软标签间的KL散度；α 为权重系数（通常0.1~0.5）；T² 为温度补偿系数，保持梯度量级稳定。
## 6.2 知识蒸馏的分类
### 6.2.1 基于响应的蒸馏（Response-based KD）
最经典的方式：蒸馏教师的最终输出（logits或软标签）。方法简单，适用于任意架构组合的师生对。代表方法：Hinton KD（2015）、Born-Again Networks（2018）。
### 6.2.2 基于特征的蒸馏（Feature-based KD）
让学生学习教师中间层的特征表示（hint learning），传递更丰富的内部知识：
FitNets（2015）：学生中间层直接匹配教师中间层特征（需投影层对齐维度）
AT（Attention Transfer）：蒸馏注意力图（特征图的通道维度求和），关注空间注意力分布
NST（Neuron Selectivity Transfer）：匹配激活模式的统计分布
RKD（Relational KD）：不匹配绝对值，而是匹配样本间的关系矩阵（相对蒸馏）
### 6.2.3 基于关系的蒸馏（Relation-based KD）
捕获样本之间的结构关系，而非单个样本的输出：
PKT（Probabilistic Knowledge Transfer）：用核密度估计匹配特征空间分布
CRD（Contrastive Representation Distillation）：基于对比学习，最大化学生与教师表示的互信息
DKD（Decoupled Knowledge Distillation）：将KL散度解耦为TCKD（目标类蒸馏）和NCKD（非目标类蒸馏），独立控制权重
## 6.3 在线蒸馏与自蒸馏
### 6.3.1 在线蒸馏（Online KD）
传统蒸馏需要预训练大教师，而在线蒸馏让多个学生网络相互学习（互蒸馏），或共享权重的多分支网络互相蒸馏。代表方法：Deep Mutual Learning（DML）。无需教师预训练，多个学生同时训练互相提升。
### 6.3.2 自蒸馏（Self-distillation）
利用网络自身的知识进行蒸馏：Born-Again Networks用同一网络的多个训练代次（generation）互蒸馏；Be Your Own Teacher则用网络的深层监督浅层，在单次训练中完成蒸馏。
## 6.4 操作Demo：完整知识蒸馏实践
### 6.4.1 教师和学生网络定义
import torch
import torch.nn as nn
import torch.nn.functional as F
import torchvision.models as models

# 教师网络：ResNet-50（大模型）
teacher = models.resnet50(pretrained=True)
teacher.eval()
for param in teacher.parameters():
param.requires_grad = False  # 冻结教师参数

# 学生网络：MobileNetV2（轻量模型）
student = models.mobilenet_v2(pretrained=False)
student.train()
### 6.4.2 蒸馏损失函数实现
class DistillationLoss(nn.Module):
'''经典Hinton蒸馏损失（响应蒸馏）'''
def __init__(self, temperature=4.0, alpha=0.4):
super().__init__()
self.T = temperature
self.alpha = alpha
self.ce_loss = nn.CrossEntropyLoss()

def forward(self, student_logits, teacher_logits, labels):
# 硬标签损失
hard_loss = self.ce_loss(student_logits, labels)

# 软标签蒸馏损失
soft_teacher = F.softmax(teacher_logits / self.T, dim=1)
soft_student = F.log_softmax(student_logits / self.T, dim=1)
soft_loss = F.kl_div(soft_student, soft_teacher,
reduction='batchmean') * (self.T ** 2)

total_loss = self.alpha * hard_loss + (1-self.alpha) * soft_loss
return total_loss, hard_loss.item(), soft_loss.item()

### 6.4.3 特征蒸馏扩展（FitNets风格）
class FeatureDistillLoss(nn.Module):
'''中间层特征蒸馏损失'''
def __init__(self, student_dim, teacher_dim):
super().__init__()
# 投影层：对齐师生特征维度
self.proj = nn.Conv2d(student_dim, teacher_dim, 1)

def forward(self, s_feat, t_feat):
# 将学生特征投影到教师特征空间
s_feat = self.proj(s_feat)
# 归一化后计算MSE损失
s_feat = F.normalize(s_feat.view(s_feat.size(0), -1), dim=1)
t_feat = F.normalize(t_feat.view(t_feat.size(0), -1), dim=1)
return F.mse_loss(s_feat, t_feat)

## 6.6 知识蒸馏前沿应用
### 6.6.1 大语言模型蒸馏
DistilBERT将BERT-base（110M参数）蒸馏为40%体积的学生模型，在GLUE基准上保留97%的性能，推理速度提升60%。MiniLM通过蒸馏self-attention关系矩阵进一步提升了蒸馏效果。
### 6.6.2 数据无关蒸馏（Data-free KD）
当原始训练数据不可用时（隐私保护、数据授权问题），可用GAN或模型逆向技术生成合成数据，配合蒸馏训练学生网络，使无数据访问的知识迁移成为可能。
本章小结
本章深入介绍了知识蒸馏的核心原理（软标签、温度参数）、三大蒸馏范式（响应/特征/关系蒸馏）以及在线蒸馏与自蒸馏。通过完整的PyTorch代码示例，实现了从基础Hinton KD到特征蒸馏的完整流程。知识蒸馏可以和剪枝、量化叠加使用，是模型压缩流水线的最后一道精度保险。

| 蒸馏方法           | 学生精度提升   | 适用场景    | 额外开销       |
| -------------- | -------- | ------- | ---------- |
| Hinton KD（T=4） | +1.5%~3% | 通用任务    | 极低         |
| FitNets（特征蒸馏）  | +2%~4%   | CNN特征学习 | 中（需投影层）    |
| AT（注意力蒸馏）      | +1.5%~3% | 视觉任务    | 低          |
| CRD（对比蒸馏）      | +3%~5%   | 表示学习    | 中（需大batch） |
| DKD（解耦蒸馏）      | +2%~4%   | 分类任务    | 低          |
