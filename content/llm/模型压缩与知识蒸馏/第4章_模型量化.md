# 第 4 章 模型量化

模型量化（Model Quantization）通过降低模型权重和激活值的数值精度（如从FP32降为INT8），在几乎不损失精度的前提下显著减少内存占用和计算量，通常可实现4倍压缩和2-4倍推理加速。

## 4.1 量化基本原理

### 4.1.1 浮点数与整数表示

标准深度学习模型使用32位浮点数（FP32）存储参数，每个参数占4字节。量化通过将浮点数映射到低位整数来压缩存储：

- **FP32 → INT8**：参数缩小4倍，推理速度提升2-4x（SIMD指令集并行计算整数）
- **FP32 → INT4**：参数缩小8倍，适用于极端压缩场景（精度损失风险更高）
- **FP32 → 二值（1-bit）**：极端稀疏化，适用于特定嵌入式场景

### 4.1.2 线性量化的数学原理

均匀（线性）量化将浮点值 r 映射到整数 q 的公式为：

```
q = round(r / S + Z)
```

其中 S 为缩放因子（scale），Z 为零点（zero-point）：

```
S = (r_max - r_min) / (2^b - 1)
Z = round(-r_min / S)
```

反量化（dequantize）将整数还原为浮点近似值：

```
r̂ = S × (q - Z)
```

### 4.1.3 对称量化与非对称量化

- **对称量化（Z=0）**：零点固定为0，计算更简单，适用于权重量化（权重分布通常对称）
- **非对称量化（Z≠0）**：允许零点偏移，可更精确捕获非对称分布（如ReLU后激活值 [0,+∞)）

## 4.2 量化方案分类

### 4.2.1 后训练量化（PTQ）

Post-Training Quantization 在已训练的FP32模型上直接量化，无需重新训练，速度最快：

- **动态量化**：推理时动态计算量化参数，适用于NLP模型（权重INT8，激活FP32）
- **静态量化**：使用校准数据集预先确定激活量化范围，适用于CNN（权重+激活均INT8）

**优点**：无需训练开销，5分钟内完成量化
**缺点**：精度损失相对较大，尤其对小模型和低位量化

### 4.2.2 量化感知训练（QAT）

Quantization-Aware Training 在训练过程中模拟量化误差（插入fake quantization节点），使模型学会适应量化，精度损失极小：

- 训练时：前向传播使用量化后的权重，反向传播使用直通估计器（STE）传递梯度
- 精度接近FP32基线（差距通常小于1%）
- 需要约10%的原始训练成本进行微调

### 4.2.3 混合精度量化

不同层对量化的敏感度不同，混合精度量化为敏感层保留较高精度（FP16/INT8），为不敏感层使用低精度（INT4），在精度与压缩率之间取得最优平衡。

## 4.3 操作Demo：PyTorch静态量化

### 4.3.1 静态量化完整流程

```python
import torch
import torchvision.models as models
from torch.quantization import get_default_qconfig, prepare, convert

# 1. 加载FP32预训练模型
model = models.resnet18(pretrained=True)
model.eval()

# 2. 配置量化方案
model.qconfig = get_default_qconfig('fbgemm')  # x86
# model.qconfig = get_default_qconfig('qnnpack')  # ARM

# 3. 插入观察器节点
model_prepared = prepare(model)

# 4. 校准（用100~200个batch的代表性数据）
with torch.no_grad():
    for images, _ in calibration_loader:
        model_prepared(images)

# 5. 转换为INT8量化模型
model_int8 = convert(model_prepared)

# 6. 对比推理速度
import time
x = torch.randn(1, 3, 224, 224)
with torch.no_grad():
    t0 = time.time()
    for _ in range(100): model(x)
    fp32_ms = (time.time()-t0)*10
    
    t0 = time.time()
    for _ in range(100): model_int8(x)
    int8_ms = (time.time()-t0)*10
    
print(f'FP32: {fp32_ms:.1f}ms | INT8: {int8_ms:.1f}ms | 加速比: {fp32_ms/int8_ms:.1f}x')
```

### 4.3.2 使用ONNX Runtime推理

```python
from onnxruntime.quantization import quantize_static, CalibrationDataReader

class MyCalibReader(CalibrationDataReader):
    def __init__(self, loader):
        self.iter = iter({'input': x.numpy()} for x,_ in loader)
    def get_next(self): 
        return next(self.iter, None)

# 导出FP32 ONNX
torch.onnx.export(model, torch.randn(1,3,224,224), 'fp32.onnx', opset_version=13)

# 量化为INT8
quantize_static('fp32.onnx', 'int8.onnx', MyCalibReader(calibration_loader))
print('ONNX INT8量化完成！')
```

## 4.5 大语言模型量化前沿

### 4.5.1 GPTQ

GPTQ是专为大型语言模型设计的逐层PTQ方法，利用二阶Hessian信息进行权重补偿，可将LLaMA-65B量化为INT4，精度损失极小，是LLM部署的主流方案。

### 4.5.2 AWQ（Activation-aware Weight Quantization）

AWQ发现1%的显著权重对精度影响极大，通过保护这些显著权重并使用逐通道缩放最小化量化误差，INT4量化性能优于GPTQ，且无需校准数据集。

### 4.5.3 SmoothQuant

SmoothQuant通过数学等价变换将激活的量化难度转移到权重上，实现W8A8（权重INT8+激活INT8）量化，在保持高精度的同时减少推理内存占用。
