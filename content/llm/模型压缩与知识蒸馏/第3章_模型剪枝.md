# 第 3 章 模型剪枝

模型剪枝（Model Pruning）通过移除神经网络中的冗余参数（权重、神经元或通道），在保持模型性能的同时减少计算量和存储需求。本章深入介绍剪枝的理论基础、主流方法与实践技巧。

## 3.1 剪枝概述

### 3.1.1 剪枝的动机

研究表明，深度神经网络普遍存在**过度参数化**现象：

- 训练好的模型中大量权重接近于零
- 许多神经元对输出的贡献微乎其微
- 删除这些冗余参数对精度影响极小

### 3.1.2 剪枝的分类

| 分类维度 | 类型 | 特点 |
|---------|------|------|
| 粒度 | 非结构化剪枝 | 删除单个权重，稀疏性高但难以加速 |
| | 结构化剪枝 | 删除整行/列/通道，硬件友好 |
| | 半结构化剪枝 | 如N:M稀疏，兼顾稀疏性和加速 |
| 时机 | 训练后剪枝 | 先训练再剪枝，最简单 |
| | 训练中剪枝 | 边训练边剪枝，如Lottery Ticket |
| | 训练前剪枝 | 随机初始化后即剪枝 |
| 范围 | 全局剪枝 | 全网络统一重要性排序 |
| | 局部剪枝 | 每层独立剪枝 |

## 3.2 非结构化剪枝

### 3.2.1 幅度剪枝（Magnitude Pruning）

最经典的方法：删除绝对值最小的权重。

```python
def magnitude_prune(model, sparsity=0.5):
    """幅度剪枝：保留幅度最大的权重"""
    for name, param in model.named_parameters():
        if 'weight' in name:
            # 计算阈值
            threshold = torch.quantile(param.abs().flatten(), sparsity)
            # 生成掩码
            mask = param.abs() > threshold
            # 应用剪枝
            param.data *= mask.float()
    return model
```

### 3.2.2 稀疏训练

训练过程中逐步增加稀疏度：

```python
def gradual_pruning_schedule(step, initial_sparsity, final_sparsity, 
                             start_step, end_step):
    """渐进式剪枝调度"""
    if step < start_step:
        return initial_sparsity
    if step > end_step:
        return final_sparsity
    
    # 立方插值
    progress = (step - start_step) / (end_step - start_step)
    return final_sparsity + (initial_sparsity - final_sparsity) * (1 - progress) ** 3
```

### 3.2.3 非结构化剪枝的局限性

| 问题 | 说明 |
|-----|------|
| 加速困难 | 需要专门的稀疏矩阵运算支持 |
| 内存不节省 | 需要存储掩码或稀疏索引 |
| 适用场景 | 学术研究、特定硬件（如GPU稀疏计算） |

## 3.3 结构化剪枝

### 3.3.1 通道剪枝（Channel Pruning）

删除完整的卷积通道，实现真正的加速：

```python
import torch_pruning as tp

def channel_prune(model, example_inputs, sparsity=0.5):
    """通道剪枝示例"""
    # 定义重要性评估器
    imp = tp.importance.MagnitudeImportance(p=2)
    
    # 创建剪枝器
    pruner = tp.pruner.MagnitudePruner(
        model,
        example_inputs,
        importance=imp,
        iterative_steps=1,
        ch_sparsity=sparsity,
    )
    
    # 执行剪枝
    pruner.step()
    return model
```

### 3.3.2 剪枝后微调

剪枝会导致精度下降，需要微调恢复：

```python
def prune_and_finetune(model, train_loader, val_loader, 
                       target_sparsity=0.5, finetune_epochs=10):
    """剪枝+微调流程"""
    # 1. 评估原始模型
    original_acc = evaluate(model, val_loader)
    print(f'原始精度: {original_acc:.2f}%')
    
    # 2. 执行剪枝
    model = channel_prune(model, torch.randn(1,3,224,224), target_sparsity)
    
    # 3. 评估剪枝后精度
    pruned_acc = evaluate(model, val_loader)
    print(f'剪枝后精度: {pruned_acc:.2f}%')
    
    # 4. 微调恢复
    optimizer = torch.optim.SGD(model.parameters(), lr=0.01, momentum=0.9)
    for epoch in range(finetune_epochs):
        train_one_epoch(model, train_loader, optimizer)
        acc = evaluate(model, val_loader)
        print(f'微调Epoch {epoch+1}: {acc:.2f}%')
    
    return model
```

### 3.3.3 依赖感知剪枝

剪枝某一层会影响后续层，需要正确处理依赖关系：

```python
# torch-pruning 自动处理依赖
DG = tp.DependencyGraph()
DG.build_dependency(model, example_inputs=torch.randn(1,3,224,224))

# 获取剪枝计划
pruning_plan = DG.get_pruning_plan(
    layer=model.conv1,
    tp.prune_conv_out_channels,
    idxs=[2, 5, 8]  # 要删除的通道索引
)

# 执行剪枝（自动处理所有依赖层）
pruning_plan.exec()
```

## 3.4 重要性评估方法

### 3.4.1 权重幅度

```python
# L1/L2范数作为重要性
importance = param.abs().sum(dim=(1,2,3))  # 每个通道的L1范数
```

### 3.4.2 梯度信息（Taylor展开）

```python
class TaylorImportance:
    """基于一阶Taylor展开的重要性"""
    def __init__(self):
        self.importance = {}
    
    def accumulate(self, name, param):
        if param.grad is not None:
            # |∂L/∂w × w| 近似剪枝对损失的影响
            self.importance[name] = (param.grad * param).abs().sum(dim=(1,2,3))
```

### 3.4.3 BN层缩放因子

BN层的γ参数可作为通道重要性指标：

```python
# BN层: y = γ * (x-μ)/σ + β
# γ接近0意味着该通道被"关闭"
bn_gamma = model.bn1.weight.data
important_channels = (bn_gamma.abs() > threshold).nonzero().flatten()
```

## 3.5 操作Demo：ResNet-50通道剪枝

### 3.5.1 完整剪枝流程

```python
import torch
import torchvision.models as models
import torch_pruning as tp

# 加载预训练模型
model = models.resnet50(pretrained=True)
model.eval()

# 定义依赖图
DG = tp.DependencyGraph()
DG.build_dependency(model, example_inputs=torch.randn(1,3,224,224))

# 重要性评估器
imp = tp.importance.TaylorImportance()

# 创建剪枝器
pruner = tp.pruner.MetaPruner(
    model,
    torch.randn(1,3,224,224),
    importance=imp,
    ch_sparsity=0.4,  # 剪掉40%通道
    ignored_layers=[model.fc],  # 不剪分类层
)

# 计算重要性（需要梯度）
for images, labels in calibration_loader:
    loss = criterion(model(images), labels)
    loss.backward()

# 执行剪枝
pruner.step()

# 统计压缩结果
macs, params = tp.utils.count_ops_and_params(model, torch.randn(1,3,224,224))
print(f'剪枝后参数量: {params/1e6:.1f}M')
print(f'剪枝后计算量: {macs/1e9:.2f}G')
```

### 3.5.2 迭代剪枝策略

```python
def iterative_pruning(model, train_loader, val_loader, 
                      target_sparsity=0.5, steps=5):
    """迭代剪枝：逐步达到目标稀疏度"""
    sparsity_per_step = target_sparsity / steps
    
    for step in range(steps):
        print(f'\n=== 剪枝步骤 {step+1}/{steps} ===')
        
        # 剪枝
        model = channel_prune(model, torch.randn(1,3,224,224), 
                             sparsity_per_step)
        
        # 微调
        finetune(model, train_loader, epochs=5)
        
        # 评估
        acc = evaluate(model, val_loader)
        macs, params = count_ops_and_params(model)
        print(f'精度: {acc:.2f}%, 参数: {params/1e6:.1f}M, MACs: {macs/1e9:.2f}G')
    
    return model
```

## 3.7 剪枝最佳实践

### 3.7.1 敏感层分析

不同层对剪枝的敏感度不同：

```python
def sensitivity_analysis(model, val_loader, prune_ratios=[0.1, 0.3, 0.5]):
    """逐层敏感度分析"""
    results = {}
    for name, layer in model.named_modules():
        if isinstance(layer, nn.Conv2d):
            results[name] = {}
            for ratio in prune_ratios:
                # 克隆模型并只剪枝当前层
                pruned_model = prune_single_layer(model, name, ratio)
                acc = evaluate(pruned_model, val_loader)
                results[name][ratio] = acc
    return results
```

### 3.7.2 关键建议

1. **保护敏感层**：第一层卷积、最后一层分类头、通道数较小的层通常对剪枝敏感
2. **渐进式剪枝**：避免一次性大幅剪枝，采用迭代剪枝+微调
3. **知识蒸馏辅助**：用原始模型作为教师指导剪枝后模型恢复精度
